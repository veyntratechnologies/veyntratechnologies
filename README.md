# ⭐ Featured Product

<div align="center">

## 👁️ NETRA AI

### **AI Eyes for the Visually Impaired**

</div>

**NETRA AI** is an AI-powered assistive technology project designed to help visually impaired users understand their surroundings through computer vision and voice-based interaction.

### ✨ Key Features

* 👁️ Real-time Object Detection
* 🔊 Voice-based Scene Description
* 📸 Snapshot Detection
* 🎙️ Voice Interaction
* 🧠 AI-powered Assistance
* 📍 Distance Estimation
* 🆘 Emergency SOS Support
* 🌐 Web-based Interface

### 🔧 Technology

`Python` `Flask` `YOLOv8` `OpenCV` `JavaScript` `Web Speech API` `AI`
